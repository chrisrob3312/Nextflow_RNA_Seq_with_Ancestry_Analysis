Input Samplesheet Format

CSV file with one row per sample. BAMs should be STAR-aligned, coordinate-sorted, and duplicate-marked.

batchYesSequencing batch (for batch correction)
sexYesM/F (used in DE covariates)
ageNoPatient age at diagnosis
tumor_purityNoEstimated tumor purity (0–1)
blast_percentageNoLeukemic blast percentage
cytomolecular_subgroupNoe.g., ETV6-RUNX1, Hyperdiploid, KMT2A-r
relapse_statusNorelapse / no_relapse
mrd_statusNopositive / negative (MRD at day 29)
adi_quartileNoArea Deprivation Index quartile (social determinant)
timepointNodiagnostic / relapse / end_of_induction
disease_stageNoDisease stage descriptor
Subworkflow 1

Preprocessing

DETECT_GENOME_BUILD & CROSSMAP_BAM

Is each BAM aligned to hg19 or hg38? Do we need to liftover?
Reads BAM headers to detect genome assembly. Automatically lifts hg19 BAMs to hg38 using CrossMap so the entire cohort is on a unified reference.
Software
samtoolsCrossMap
Output
hg38-aligned BAMs for all samples

QC: SAMTOOLS_FLAGSTAT / IDXSTATS / STATS

What is the quality of each BAM? Total reads, mapped %, duplicates?
Computes alignment statistics: total reads, mapped reads, properly paired reads, unmapped reads, duplicate rate, insert size distribution. Catches library failures and contamination early.
Software
samtools flagstatsamtools idxstatssamtools stats
Output
Per-sample QC metrics → MultiQC

RSEQC_BAMSTAT / READDISTRIBUTION / INFEREXPERIMENT

How are reads distributed across gene features? What is the library strandedness?
RNA-seq-specific QC: reads mapping to exons vs. introns vs. intergenic regions, 5′/3′ bias, junction saturation, and automatic strand detection (unstranded, fr-firststrand, fr-secondstrand).
Software
RSeQC
Output
Read distribution, strandedness, gene body coverage

PICARD_COLLECTRNASEQMETRICS

What fraction of bases map to coding, UTR, intronic, and ribosomal regions?
Detailed RNA-seq metrics including coding/UTR/intronic/intergenic base fractions, median CV of coverage, and 5′/3′ bias to assess library prep quality.
Software
Picard CollectRnaSeqMetrics
Output
Per-sample RNA metrics → MultiQC

SUBREAD_FEATURECOUNTS → MERGE_COUNTS

How many reads map to each gene?
Quantifies gene-level expression by counting reads overlapping annotated gene features (GENCODE v44). Per-sample counts are merged into a single gene × sample count matrix for downstream analysis.
Software
Subread featureCounts
Output
Raw count matrix (genes × samples TSV)

NORMALIZE_COUNTS & BATCH_CORRECTION

Are expression values comparable across samples? Are there batch effects?
Applies VST (variance-stabilizing transformation) or rlog normalization via DESeq2, then optionally corrects for batch effects using ComBat-seq or SVA. Critical for multi-batch cohorts where technical variation can obscure biology.
Software
DESeq2svaComBat-seq
Output
Normalized + batch-corrected count matrix
Subworkflow 2

Genomics

EXTRACT_GRAF_SNPS → MERGE_GRAF_VCFS → GRAFANC_RUN → ANCESTRY_INFERENCE

What is each patient's genetic ancestry? Do ancestry proportions confound other results?
Extracts genotypes at 282K ancestry-informative SNP positions using bcftools mpileup from RNA-seq BAMs. GRAF-anc computes geometric genetic distances to continental reference populations, yielding barycentric ancestry coordinates (European, African, East Asian). Results are used as covariates in DE, and for stratifying neoantigen burden and drug sensitivity by ancestry.
Software
bcftools mpileup/callGRAF-anc (grafpop)R (PCA, ancestry assignment)
Output
Ancestry proportions per sample, ancestry categories, PCA coordinates

SOMALIER_EXTRACT → SOMALIER_RELATE

Are there sample swaps, unexpected duplicates, or related individuals in the cohort?
Extracts ~17K coding-region SNPs per sample and computes pairwise relatedness coefficients. Detects sample swaps, mislabeled samples, and cryptic relatedness. Also provides sex verification and an independent ancestry check.
Software
Somalier
Output
Relatedness matrix, sample-swap flags, sex concordance

GATK SplitNCigarReads → BQSR → HaplotypeCaller → VariantFiltration

What somatic and germline variants are present in each tumor RNA-seq sample?
GATK RNA-seq best practices: splits reads spanning splice junctions (SplitNCigarReads), recalibrates base quality scores (BQSR) using dbSNP, calls variants with HaplotypeCaller, and hard-filters for quality. Produces per-sample filtered VCFs used for neoantigen prediction and pharmacogenomic annotation.
Software
GATK 4.x
Output
Per-sample filtered VCF + index

CHASMPLUS

Which variants are likely cancer driver mutations vs. passengers?
Runs OpenCRAVAT with the CHASMplus annotator to score each variant for driver vs. passenger probability. Uses a random-forest model trained on known oncogenic mutations. Variants with p < 0.05 are flagged as predicted drivers.
Software
OpenCRAVATCHASMplus
Output
Driver/passenger classifications with p-values

CREATE_MAF

Can we visualize the mutational landscape with maftools (oncoplots, lollipop plots)?
Converts filtered VCFs to MAF (Mutation Annotation Format) using vcf2maf with VEP annotation. The MAF file is compatible with maftools for oncoplot generation, mutational signature analysis, and recurrence summaries.
Software
vcf2mafVEP
Output
maftools-compatible MAF file

TMB_ESTIMATION

What is each sample's tumor mutational burden? Does higher TMB predict immunotherapy response?
Counts nonsynonymous mutations per megabase of coding sequence from filtered VCFs. TMB is a biomarker for checkpoint inhibitor response in some contexts and is correlated with neoantigen load.
Software
R (custom)
Output
TMB scores per sample

ARCASHLA_EXTRACT / GENOTYPE / MERGE & OPTITYPE

What HLA alleles does each patient carry? (Required for neoantigen binding prediction)
Types HLA class I (A, B, C) and class II (DPB1, DQB1, DQA1, DRB1) alleles directly from RNA-seq reads. arcasHLA extracts HLA-mapped reads and determines the most likely allele pair per locus. OptiType provides an independent class I prediction. HLA types feed into pVACseq for MHC binding affinity.
Software
arcasHLAOptiType
Output
4-digit HLA allele calls per sample
Subworkflow 3

Expression Analysis

DESEQ2_DE & LIMMA_VOOM_DE

Which genes are differentially expressed between conditions (e.g., relapse vs. non-relapse, by subtype)?
Runs two complementary DE methods. DESeq2 uses a negative binomial GLM with Wald test; limma-voom applies empirical Bayes moderated t-statistics after precision weight estimation. Both incorporate ancestry as a covariate (via the proportions from GRAF-anc) alongside batch, sex, age, and blast percentage. Contrasts are defined in a JSON file for flexible group comparisons.
Software
DESeq2limma-voom
Output
DE result tables (log2FC, padj), volcano/MA plots

WGCNA_ANALYSIS

Are there co-expressed gene modules that correlate with clinical traits or ancestry?
Weighted Gene Co-expression Network Analysis identifies modules (clusters) of genes with correlated expression patterns. Each module is tested for association with clinical traits (relapse, MRD, subtype, ancestry) using Pearson correlation of module eigengenes. Hub genes within trait-associated modules become candidate biomarkers.
Software
WGCNA
Output
Module assignments, trait correlations, hub gene lists

PATHWAY_ENRICHMENT

What biological pathways and processes are dysregulated?
Tests DE gene lists for enrichment in curated pathway databases: GO Biological Process, GO Molecular Function, KEGG, Reactome, Hallmark, and ImmuneSigDB. Uses both over-representation analysis (ORA, hypergeometric test) and gene set enrichment analysis (GSEA, ranked by DE statistics) for complementary perspectives.
Software
clusterProfilerfgseamsigdbr
Output
Enrichment tables, dot plots, GSEA enrichment plots, network visualizations

GSVA_ANALYSIS

What is each sample's activity score for specific gene sets (e.g., Hallmark pathways)?
Gene Set Variation Analysis computes per-sample pathway activity scores in an unsupervised manner (no group labels needed). Useful for clustering samples by pathway activity, correlating pathway scores with clinical variables, and identifying patient-specific pathway dysregulation.
Software
GSVA
Output
Per-sample pathway scores matrix
Subworkflow 4

Structural Variants

LEAFCUTTER (Junctions → Cluster → Diff Splicing)

Are there differentially used splice junctions between conditions?
Leafcutter identifies variable splicing events by clustering intron-spanning reads into "intron clusters" and testing for differential excision ratios between groups. Unlike exon-based methods, it discovers novel splice junctions without relying on transcript annotations.
Software
Leafcutter
Output
Differentially spliced intron clusters, PSI changes

SPLADDER_BUILD → BISBEE (Prep / Diff / Prot / Outlier)

Which alternative splicing events create novel protein sequences (neojunctions)?
SplAdder builds augmented splice graphs from RNA-seq data, identifying exon skipping, intron retention, alternative 5′/3′ splice sites, and novel exons. BISBEE extends this by translating splicing events to protein-level consequences and identifying patient-specific outlier splicing events (potential neoantigen sources).
Software
SplAdderBISBEE
Output
Alternative splicing events, protein consequences, outlier events

FUSIONCATCHER & ARRIBA (+ Visualization) → MERGE_FUSIONS

Which gene fusions are present? Are there known oncogenic fusions (e.g., ETV6-RUNX1, BCR-ABL)?
Two independent fusion callers for high sensitivity and specificity. FusionCatcher uses a database of known fusions and multiple alignment algorithms. Arriba is optimized for RNA-seq with visualization of chimeric read support across genomic coordinates. Results are merged and filtered by minimum supporting reads.
Software
FusionCatcherArriba
Output
Fusion calls per sample, circos-style visualizations, merged consensus list

INFERCNV

Are there large-scale copy number alterations visible from expression data?
Infers copy number variations from RNA-seq by comparing expression profiles of tumor samples against a reference (normal samples or average expression). Detects chromosomal gains, losses, and focal amplifications. Particularly useful in B-ALL for identifying hyperdiploidy, hypodiploidy, and iAMP21.
Software
inferCNV
Output
CNV heatmaps, chromosome-level gain/loss calls
Subworkflow 5

Immunogenomics

IMMUNE_DECONVOLUTION & ESTIMATE_SCORES

What is the immune cell composition of each tumor? Is the microenvironment immunologically "hot" or "cold"?
Estimates immune cell type fractions using six complementary algorithms: CIBERSORT, MCP-counter, quanTIseq, TIMER, EPIC, and xCell. ESTIMATE separately scores immune activity, stromal content, and tumor purity. Together these reveal whether tumors are immune-infiltrated (potentially responsive to immunotherapy) or immune-desert.
Software
immunedeconvESTIMATE
Output
Immune cell fraction matrices, ESTIMATE scores, comparison plots

PVACSEQ

Which somatic mutations produce peptides that bind the patient's HLA alleles (SNV/indel neoantigens)?
Predicts MHC class I and class II binding affinity for all mutant peptides derived from somatic variants. Uses the patient's HLA alleles (from arcasHLA) and multiple prediction algorithms (NetMHCpan, MHCflurry). Filters by IC50 < 500 nM and DAI (differential agretopicity index) to identify candidate neoantigens.
Software
pVACseq (pVACtools)
Output
Ranked neoantigen candidates with binding affinity

NEOFUSE

Do any gene fusions produce novel peptides that are immunogenic?
Predicts neoantigens arising from fusion gene junctions. Translates the fusion junction in all reading frames, generates candidate peptides spanning the breakpoint, and predicts HLA binding affinity. Fusion-derived neoantigens are particularly relevant in B-ALL where fusions are driver events.
Software
NeoFuse
Output
Fusion-derived neoantigen candidates

SNAF_SPLICING_NEOANTIGENS

Do aberrant splicing events produce novel peptides that could be immunogenic?
SNAF (Splicing Neo Antigen Finder) identifies neoantigens from alternative splicing events. Translates tumor-specific junctions, generates peptides, and predicts HLA binding. Splicing-derived neoantigens are a distinct class from SNV neoantigens and expand the targetable neoantigen repertoire.
Software
SNAF
Output
Splicing-derived neoantigen candidates

TELESCOPE_HERV & HERVQUANT

Are human endogenous retroviruses (HERVs) and transposable elements aberrantly expressed in tumors?
Telescope performs TE-aware read assignment to quantify expression of HERV and transposable element loci from RNA-seq. hervQuant provides a complementary quantification using a curated HERV reference. HERV-derived peptides represent a fourth class of tumor-associated antigens (alongside SNV, fusion, and splicing neoantigens) and have been linked to immune activation in some cancers.
Software
TelescopehervQuant
Output
Per-locus HERV/TE expression counts

NEOANTIGEN_BURDEN_ANALYSIS

Does neoantigen burden differ by relapse, MRD status, or ancestry? Within MRD-negative patients, does relapse status correlate with neoantigen load or composition?
Aggregates neoantigens from all sources (SNV, fusion, splicing, HERV) per sample. Performs stratified comparisons: (1) relapse vs. non-relapse (Wilcoxon), (2) MRD+ vs. MRD− (Wilcoxon), (3) ancestry groups (Kruskal-Wallis). Additionally, nested stratification within MRD-negative patients: tests relapse vs. non-relapse burden by neoantigen type, ancestry category within each relapse stratum (Kruskal-Wallis), and Spearman correlations between continuous ancestry proportions and neoantigen counts.
Software
R (data.table, ggplot2)
Output
Burden tables, comparison statistics, boxplots (relapse, MRD, ancestry), nested MRD-neg strata plots

ANTIGEN_DB_CROSSREF

Do any predicted neoantigens match known cancer antigens (TANTIGEN 2.0)?
Cross-references all predicted neoantigens against a curated cancer antigen database. Hits represent peptides with prior evidence of immunogenicity, increasing confidence in their therapeutic potential.
Software
Python (pandas)
Output
Matched neoantigen–known-antigen pairs, summary statistics

TRUST4 → MERGE_TCR_REPORTS

What TCR/BCR clonotypes are present in the tumor? Is there evidence of clonal T-cell expansion?
TRUST4 reconstructs T-cell receptor (TCR) and B-cell receptor (BCR) CDR3 sequences directly from RNA-seq reads (no dedicated TCR-seq needed). Clonotype diversity, clonal expansion, and dominant clone frequency can indicate adaptive immune responses against the tumor.
Software
TRUST4
Output
CDR3 sequences, clonotype tables, diversity metrics
Subworkflow 6

Clinical Analysis

SENSITIVITY_ANALYSIS

Which drugs might each patient's tumor be sensitive to, based on expression-drug response models?
Predicts drug sensitivity using expression-based models trained on cancer cell line panels (GDSC). Ridge regression models relate gene expression to drug response (IC50/AUC), then predict each patient sample's sensitivity profile. Results are stratified by ancestry to detect population-level differences in predicted drug response.
Software
R (glmnet, pRRophetic)
Output
Per-sample predicted drug sensitivity scores, ancestry-stratified comparisons

PHARMACOGENOMICS

Do patients carry pharmacogenomic variants that affect drug metabolism or efficacy?
Annotates variants from RNA-seq VCFs against pharmacogenomic databases (PharmGKB, CPIC). Identifies clinically actionable variants affecting drug metabolism (e.g., CYP2D6, TPMT, NUDT15) that may guide dose adjustments or drug selection in B-ALL treatment protocols.
Software
R (custom)
Output
Pharmacogenomic variant annotations, clinical recommendations

OCTAD_ANALYSIS

Which existing drugs could reverse the disease gene expression signature?
Uses the OCTAD package to query the LINCS L1000 connectivity map with disease signatures derived from DE results. Computes sRGES (summarized Reversal Gene Expression Score) for ~20K drugs. Drugs with the most negative sRGES are predicted to reverse the disease expression phenotype — a computational drug repurposing approach.
Software
OCTADLINCS L1000
Output
Ranked drug candidates by sRGES, bar plots, recurrent hits across contrasts

PHARMACOGX_ANALYSIS

Can we predict per-patient drug sensitivity using multiple large-scale pharmacogenomic databases?
Downloads PharmacoSets from three databases (GDSC2, CTRPv2, gCSI) and trains ridge regression models for each drug using cell line expression and drug response data (AAC). Predicts drug sensitivity for each patient sample and tests for ancestry-associated differences using Kruskal-Wallis tests. Cross-database concordance increases confidence in predictions.
Software
PharmacoGxglmnet
Output
Per-database drug sensitivity matrices, ancestry comparisons, heatmaps

DREAM_DRUGGABILITY

Which DE genes are most druggable based on their network connectivity? What drug combinations target complementary pathways?
Builds Pearson co-expression networks from DE genes using igraph, computes topology metrics (degree, betweenness, closeness, eigenvector centrality), and generates composite druggability scores. Uses Louvain community detection to identify pathway modules, then suggests drug combinations that target distinct modules for synergistic therapeutic coverage.
Software
igraphR (custom)
Output
Druggability rankings, network plots, drug combination candidates

SIGNATURESEARCH_ANALYSIS

Which drugs in the LINCS L1000 database produce the opposite expression signature to our disease?
Uses the signatureSearch Bioconductor package with the CMAP (Connectivity Map) method to query LINCS L1000 locally. Ranks ~10K perturbagens by Normalized Connectivity Score (NCS). Adds Drug Set Enrichment Analysis (DSEA) to identify enriched mechanisms of action among top-ranked drugs, revealing actionable therapeutic classes rather than individual compounds.
Software
signatureSearchsignatureSearchData
Output
Drug rankings by NCS, MOA enrichment tables, dot plots

MOLECULAR_SUBTYPING

What molecular subtype does each sample belong to? Does expression-based classification agree with cytogenetics?
Classifies samples into molecular subtypes using expression-based signatures. For B-ALL, this includes cytomolecular groups (ETV6-RUNX1, Hyperdiploid, KMT2A-r, BCR-ABL1, Ph-like, DUX4, PAX5alt, etc.). Compares expression-derived classifications with clinical cytogenetics/FISH data to identify discordant cases that may have been misclassified.
Software
R (custom classifiers)
Output
Subtype assignments, concordance with clinical labels, confusion matrix

Info

Two Pipeline Versions

Nextflow DSL2 Pipeline (Primary)

The main pipeline using Nextflow's channel-based dataflow. Handles dependency resolution automatically, supports Docker/Singularity containers per process, has built-in resume on failure (-resume), and generates execution reports.
Config files
nextflow.config, conf/containers.config, conf/modules.config
Run command
nextflow run main.nf --input samplesheet.csv --fasta ref.fa --gtf genes.gtf -profile docker

SBATCH Version (HPC Alternative)

Standalone SLURM batch scripts mirroring the same analyses. Uses individual sbatch scripts with explicit --dependency=afterok chains. For HPC environments without Nextflow/containers, or when you want to run/debug individual steps manually.
Config
SBATCH_Version/config.sh (shared paths, params, helpers)
Run command
./SBATCH_Version/submit_all.sh or individual sbatch calls
